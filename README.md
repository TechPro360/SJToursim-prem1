# 🌾 SJToursim-prem1 — San Jose City Tourism Portal

An Awwwards-caliber, interactive tourism portal celebrating **San Jose City, Nueva Ecija, Philippines** — the *Golden Grain and Onion Capital of the Philippines*.

---

## 🌟 Key Features

1. **Awwwards-Level Loading Experience**:
   - Pure minimalist white canvas with real-time percentage counter (`00%` ➔ `100%`).
   - Grounded Philippine Jeepney riding a highway progress line with GSAP suspension bounce and drifting dust physics.
   - Dynamic cultural milestone narrative (`Central Luzon Expressway` ➔ `Tanduyong Harvest` ➔ `Caraballo Foothills` ➔ `San Jose City Gateway`).
   - Smooth curtain lift transition into the destination landing page.

2. **Official Seal Color Identity (1969)**:
   - **Palay & Sierra Madre Green** (`#00843D`): Lush agricultural heartland and mountain foothills.
   - **Harvest Sun Gold** (`#FFC72C` / `#D97706`): The central four-point sun cross and ripening palay.
   - **Tanduyong Onion Crimson** (`#B8263E`): The iconic red bulb onion celebrating the Tanduyong Festival.
   - **Freshwater Cerulean** (`#0284C7`): Mountain reservoirs and eco-sanctuaries.
   - **Carabao Soil Brown** (`#5C3D2E`): Agrarian strength and heritage.

3. **Curated Tourism Highlights**:
   - **Tanduyong Festival**: Annual street dancing pageantry and agricultural floats.
   - **Tayabo Nature Reserve**: Freshwater reservoir, wooden eco-decks, and mountain breezes.
   - **Diamond Park Hilltop**: 100+ stone steps leading to panoramic Caraballo valley vistas.

4. **Interactive Virtual Jeepney Safari**:
   - Tap stations along the Maharlika Highway route to watch the Jeepney navigate directly to key historical, agrarian, and eco-tourism stops with local traveler insider tips.

5. **Responsive & Mobile-First**:
   - Adaptive scaling across all mobile phones, tablets, and desktops.
   - Touch drawer navigation and thumb-friendly tap targets.
   - Lenis smooth inertial scrolling.

---

## 🚀 Tech Stack

- **Framework**: React 18
- **Bundler & Dev Server**: Vite
- **Animations & Physics**: GSAP (GreenSock)
- **Smooth Inertial Scrolling**: Lenis
- **Icons**: Lucide React
- **Typography**: Syne, Plus Jakarta Sans, Space Grotesk

---

## 🛠️ Getting Started

```bash
# Clone the repository
git clone https://github.com/TechPro360/SJToursim-prem1.git

# Navigate to project directory
cd SJToursim-prem1

# Install dependencies
npm install

# Start development server
npm run dev
```
